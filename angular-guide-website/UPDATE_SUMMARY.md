## 🆕 What's New

### Added Angular 21 & 22 Complete Coverage

#### **Angular 21 Features (November 2025)**
- **@Service Decorator** - New simplified service declaration with automatic injection tokens
- **NgModuleFactory Removal** - Breaking change requiring migration to standalone components
- **Enhanced NgComponentOutlet** - Improved support for injectors and input binding
- **TestBed PlatformLocation** - Proper mocking instead of null
- **Enhanced Server-Side Rendering** - Improved SSR bootstrap patterns

#### **Angular 22 Features (May 2026)**
- **TypeScript 6.0+ Requirement** - Breaking change, no longer supports older versions
- **ComponentFactoryResolver Removal** - Complete deprecation of factory resolver
- **Enhanced Router Interfaces** - Refined typing for better type safety
- **Case-Insensitive Resource URL Sanitizer** - Better URL handling
- **SVG Namespace Support** - Built-in XML namespace handling
- **Zoneless Change Detection Preview** - Experimental Zone.js-free change detection
